# electerm_slim 隐私说明

书签、连接配置和历史等数据保存在本机。软件沿用现有的数据保护和系统安全存储机制。

检查更新时会向本仓库的 GitHub Releases API 请求版本和附件信息，不附带书签数量、语言、同步配置或启动时间等使用统计。下载安装包时会访问 GitHub 的附件地址。

连接远程主机、使用 AI 或启用同步时，相关数据会发送到用户配置的主机或服务。AI 和同步服务需要自行配置；本项目不提供默认的云同步或免费 AI 服务。

提交问题、日志或截图前，请自行移除密码、密钥和其他私密信息。反馈入口为 [本仓库 Issues](https://github.com/fayev1t/electerm_slim/issues)。
